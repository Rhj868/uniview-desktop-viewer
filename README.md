# UniView

UniView 是面向 Windows 的本地多格式文件查看工具。它提供目录浏览、文件预览、跨格式搜索以及双栏对照，方便在同一个窗口里查看不同类型的资料。

## 功能

- 浏览本机文件夹，打开多个文件并通过标签切换。
- 查看 Markdown、文本、HTML、PDF、图片和多种代码文件。
- 预览 Word、Excel、PPT 及部分 WPS 格式；按环境提供 WPS 嵌入和外部程序打开选项。
- 搜索支持的文件正文，包括部分 Office 文件；支持双栏并排查看。
- 编辑和保存 Markdown、TXT 等受支持的文本文件。

不同格式的预览和文本提取效果取决于文件内容及本机环境，复杂 Office 排版不保证与原软件完全一致。搜索有文件数量和大小限制，未命中不代表内容一定不存在。

## 在 Windows 上从源码启动

需要安装 Python 和 Microsoft Edge 或 Google Chrome。WPS 用于可选的 WPS 集成功能；Office 内置预览功能因格式而异。

在项目目录中运行：

```bat
python server.py
```

也可双击 `UniView.pyw` 使用无控制台启动。软件使用本机服务并打开独立窗口。启动后，选择文件夹或输入完整路径，再点击左侧文件查看。

本项目依赖的前端库已放在 `vendor/`。启动源码不需要安装额外的 Python 包。`UniView.spec` 是 PyInstaller 打包配置，打包需要另行安装 PyInstaller；安装包构建过程尚未在本仓库验证。

## 常用操作

1. 在窗口顶部切换目录或输入文件、文件夹路径。
2. 点击左侧文件打开，使用顶部标签切换文件。
3. 在顶部搜索框输入关键词并点击“搜索”。
4. 先打开至少两个文件，再点击“并排打开”；拖动分隔线可调整宽度。
5. 可编辑文件使用“编辑”和“保存”；保存会写回原文件。建议对重要文件先备份。

关闭窗口通常即可结束本次使用；如需停止后台服务，可点击界面中的“结束服务”。请只打开信任的 HTML 文件。
